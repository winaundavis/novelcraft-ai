# NovelCraft AI 回归测试清单

## 一、项目管理

- [ ] 新建项目：书名/梗概/题材/字数/章节/风格 全部填写 → 创建成功 → 跳转工作区
- [ ] 项目列表：显示所有项目（含名称/字数/状态/日期）
- [ ] 搜索：输入关键词能过滤项目
- [ ] 三点菜单：置顶/移到最前/打开/删除 四个操作均正常
- [ ] 删除项目：确认后从列表移除

## 二、大纲生成

- [ ] 输入梗概 → 选择结构 → 点击生成 → 等待完成 → 章节树更新
- [ ] AI 生成失败时，前端降级为本地大纲
- [ ] 章节树：折叠/展开卷、点击章节切换

## 三、写作编辑器

- [ ] 编辑器：编辑模式输入、预览模式渲染、分屏模式
- [ ] AI 续写：填写方向 → 选择字数 → 点击续写 → 等待流式输出
- [ ] SSE 中断时，前端补本地续写内容
- [ ] 保存按钮：保存后"未保存"提示消失
- [ ] 字数统计：实时更新

## 四、人物工坊

- [ ] 创建人物：填写姓名/定位 → 创建成功 → 出现在列表
- [ ] AI 生成失败时，前端本地创建基础人设卡
- [ ] 人物详情：大五人格/背景/动机/弧线 均展示
- [ ] 删除人物：从列表移除

## 五、智能审校

- [ ] 点击审校 → 等待完成 → 显示评分（语言/逻辑/节奏）
- [ ] 问题列表：按严重度筛选（全部/致命/重要/建议）
- [ ] 审校失败时，前端本地给出基础建议
- [ ] 计数准确：列表条目数与筛选项数字一致

## 六、导入功能

- [ ] Markdown 文件夹：输入路径 → 扫描 → 显示章节列表
- [ ] Word 建议书：上传/路径 → 解析 → 显示建议列表
- [ ] 建议应用：逐条应用建议到编辑器
- [ ] 导入分析：显示人物/地点/时间线/伏笔

## 七、世界观

- [ ] 六个分类卡片均显示
- [ ] 规则 CRUD：添加/编辑/删除/保存
- [ ] 空状态：无规则时显示引导提示

## 八、技法分析

- [ ] 输入参考文本 → 开始分析 → 显示技法报告
- [ ] 风格量化对比图正常渲染
- [ ] 分析失败时显示错误信息

## 九、数据看板

- [ ] 总字数/章节数/人物数 正确统计
- [ ] 字数趋势图、章节分布、人物频次 正常渲染
- [ ] 空状态：无数据时显示引导

## 十、设置页

- [ ] 模型配置 CRUD：添加/激活/删除
- [ ] 未配模型时 AI 接口返回 503
- [ ] 配置持久化：刷新后保留

## 十一、AI 聊天

- [ ] 输入消息 → 发送 → 收到回复
- [ ] 快速操作按钮：续写/增强/头脑风暴/创建人物
- [ ] 后端不可用时本地返回建议
